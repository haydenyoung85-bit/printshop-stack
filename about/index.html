About

Print Shop Stack is a directory of tools and suppliers for people who run small 3D print businesses. It is run by Hayden Young, owner of Haddy's Creations, a small print shop that uses a Bambu Lab P2S.

Listings summarize public information from each vendor's official site. We don't publish ratings or invented reviews. Unless a page says otherwise, we haven't tested the product hands-on.

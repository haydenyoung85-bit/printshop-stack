OctoPrint

What it is

Open-source web interface for controlling and monitoring a single 3D printer, usually run on a Raspberry Pi, with a large plugin ecosystem.

Who it's for

Owners of printers that use standard serial/G-code control who want local, self-hosted control.

Pricing

Free and open source (donation-funded).

Taken from the official site on 2026-10-20. Prices change, so confirm before you buy.

Pros

  • Free and open source
  • Large plugin library
  • Runs locally with no cloud account required

Cons

  • One instance per printer, so farms need extra tooling
  • Not designed around Bambu Lab's closed ecosystem
  • Requires your own hardware and setup
